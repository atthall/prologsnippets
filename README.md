# Logikai rejtvény megoldó Prolog program

## Domino_verseny.pl
Ez a program a Füles újságban megjelent **Domino Verseny logikai rejtvény** megoldását valósítja meg Prolog nyelven.
A feladatban öt versenyző vezetéknevét, keresztnevét, klubját és helyezését kell meghatározni a megadott feltételek alapján.
A program logikai szabályok és kizáró feltételek segítségével állítja elő az egyetlen helyes sorrendet.
